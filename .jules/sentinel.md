## 2024-05-18 - [DOM-Based XSS in Custom Link Routing]
**Vulnerability:** A DOM-based Cross-Site Scripting (XSS) vulnerability existed in `premium.js` where custom link routing logic intercepted clicks and executed `window.location.href = href`. The check intended to filter out JavaScript execution only checked `href.startsWith('javascript')`, allowing whitespace-padded payloads like ` javascript:` or `data:` URIs to execute when the link was clicked.
**Learning:** Checking for malicious URIs using simple string methods like `startsWith` is insufficient, as browsers automatically trim and ignore leading whitespace in URIs. Malicious links like `<a href=" javascript:alert(1)">` bypass `startsWith` but execute normally in `window.location.href`.
**Prevention:** Always use a rigorous regex pattern like `/^\s*(javascript|data)\s*:/i` to validate URIs, ensuring that no variation of malicious protocols can bypass the security checks before passing them to sensitive execution sinks like `window.location.href`.
